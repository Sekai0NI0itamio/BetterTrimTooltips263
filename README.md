# Better Trim Tooltips (26.3 Port)

Unofficial port of [Better Trim Tooltips](https://modrinth.com/mod/better-trim-tooltips)
by Andrew6rant for Minecraft 26.3 (Fabric).

This mod condenses the tooltips of trimmed armor pieces from multiple lines into one line.

> All credit for the original concept, design, and logic goes to
> [Andrew6rant (Andrew Grant)](https://github.com/Andrew6rant/Better-Trim-Tooltips).

## Requirements

- Minecraft 26.3
- Fabric Loader >= 0.20.1
- Fabric API
- Java 25

## Build

```bash
./gradlew build
```

The resulting JAR is in `build/libs/bettertrimtooltips263-*.jar`.

CI builds are run via GitHub Actions (`.github/workflows/build.yml`).
